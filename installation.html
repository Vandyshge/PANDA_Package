Installation

The package is named panda-md, the Python module is panda_md, and the shell command is panda.

Install from source

Use Python 3.10 or newer. This manual targets the developer repository’s 0.1.0 alpha API. The source checkout requires repository access.

Shell
git clone https://github.com/Ilya-Garanov-WorkingAcc/PANDA_2.0.git
Shell
cd PANDA_2.0
python -m venv .venv

Activate the environment with source .venv/bin/activate on macOS or Linux, or .venv\Scripts\Activate.ps1 in PowerShell.

Shell
python -m pip install .

Optional dependencies

From the same checkout, install the md extra for trajectory input and plot for Matplotlib figures.

Shell
python -m pip install ".[md,plot]"

Check the installation

Python
import panda_md

print("PANDA import OK")
Output
PANDA import OK

Run panda --help in a shell to list the available commands.
