Pores and shapes

A pore defines the confinement geometry. A named shape defines the analytical interface inside it.

Set up a pore

Choose a pore to open its 3D shape gallery.

pore.interface("roll") selects an analytical model for the slit. Polygon names encode the number of walls touched (w) and corners occupied (c).

Limits of the models

Slit and cylindrical contact-angle models cover the non-wetting side of 90°. Some polygon models have narrower domains. Models such as a flat layer have no contact-angle parameter. Check model.is_feasible(...) and model.phi_limits(...) for the specific shape.
