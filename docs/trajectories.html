From a trajectory

Read a GROMACS or LAMMPS trajectory, inspect the contact angle across the full run, and fit a selected averaging window.

Download and run the examples

Extract md-trajectory-examples.zip and install PANDA with the md and plot extras. Run these commands from the extracted directory. Both examples use the same 201 independently generated particle frames, spanning 0–10 ns at 50 ps intervals. The input angle is 120°. The time axis exercises the trajectory workflow on synthetic coordinates.

Shell
python md_gromacs.py
python md_lammps.py

Each script writes an NPZ with the full-run block profiles, an NPZ with the averaged profile, and a PNG with three diagnostic panels.

Choose an example

  • GROMACS · GRO topology, XTC trajectory, and residue selections.
  • LAMMPS · DATA topology, custom dump, atom types, and timestep.
  • Full trajectory and averaging window · profile, density map, and angle history.
  • Fit saved blocks · reuse existing density profiles.
