InterfaceModel.fit

panda_md.InterfaceModel.fit

fit(
    profile: core.profile.DensityProfile,
    *,
    optimize: Sequence[str] | None = None,
    fixed: Mapping[str, float] | None = None,
    bounds: Mapping[str, tuple[float, float]] | None = None,
    initial: Mapping[str, float] | None = None,
    normalization: core.enums.Normalization = Normalization.AUTO,
    density_bulk_per_nm3: float | None = None,
    loss: core.enums.LossFunction = LossFunction.L1,
    window: tuple[float, float] | None = None,
    starts_per_parameter: int = 5,
    optimizer: core.enums.OptimizerMethod = OptimizerMethod.NELDER_MEAD,
    regime: core.enums.Regime | None = None,
) -> FitResult

Fit one DensityProfile and return a FitResult. Set density_bulk_per_nm3 for bulk normalization. The default loss is mean absolute deviation.

Parameters

ArgumentMeaning
profileDensityProfile in physical units.
optimize, fixedChoose the free parameter names or assign fixed values. An omitted optimize uses the model defaults.
bounds, initialOptionally narrow parameter bounds and supply an extra starting point in user units.
normalization, density_bulk_per_nm3Auto normalization uses bulk density if supplied, otherwise the profile mean density.
windowFit interval on the reduced profile coordinate.
regimeRestrict the search to a supported wetting regime.
