Fitting and interpretation

Fit a candidate interface, inspect its diagnostics, and compare models in the physically accessible domain.

Fit a saved profile

Download density.csv into the working directory. It contains the synthetic slit-pore profile from the quick start in physical units. A headerless input file contains coordinate in nm, number density in nm⁻³, and an optional uncertainty column. Center the coordinates consistently with the analytical pore.

Python
from panda_md import DensityProfile, SlitPore

profile = DensityProfile.load("density.csv")
pore = SlitPore(width_nm=8.0, length_nm=16.0)
result = pore.interface("roll").fit(
    profile, optimize=["theta", "delta"], density_bulk_per_nm3=30.0,
)
print(result.summary())
print(result.problems())
Output

   theta = 120.614  (free)
   delta = 0.0300547  (free)
     phi = 0.40016  (fixed)
   shift = 0  (fixed)
()

An empty tuple () means PANDA reported no diagnostic flags for this fit.

Parameters and normalization

theta is the contact angle in degrees for the analyzed phase. delta is the effective wall-layer thickness as a fraction of the characteristic pore size. phi is the analyzed liquid’s volume fraction. shift is an offset along the profile coordinate in pore-size units, fixed at zero by default.

With bulk normalization, PANDA divides the input density by ρbulk and can estimate φ from the profile. With mean normalization, supply the profile’s particle count and pore volume, and fix or optimize φ if the bulk density is unavailable.

Fit diagnostics

The default L1 objective is the mean absolute deviation of the normalized profiles. PANDA runs Nelder–Mead from multiple starting points. Inspect convergence, feasibility, parameter bounds, and the at_regime_boundary flag. A boundary fit near 90° may indicate that the selected model’s angular range is too restrictive.

Compare shapes and stability

compare_shapes(pore, profile, spec) ranks available profiles by fit loss. Near-ties can occur when different interfaces project to nearly the same one-dimensional density. Inspect the density map or snapshots before assigning a morphology.

stability_diagram(...) ranks feasible shapes by the capillary surface term SLV − cos θ SSL at prescribed angle and layer thickness. Each operation has its own set of supported shapes in the catalog.
