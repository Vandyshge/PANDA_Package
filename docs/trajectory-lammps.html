LAMMPS

Read a DATA topology and a custom trajectory dump.

Run the LAMMPS example

Download the example files and install the extras.

The example pairs an atom_style atomic DATA file with a custom dump. Type 1 is the wall and type 2 is the selected liquid. For your run, substitute its atom types and set atom_style to the columns in the DATA file’s Atoms section. The dump and DATA file must have matching atom IDs.

Python
from panda_md import load_trajectory

from md_workflow import analyze


traj = load_trajectory(
    "slit.data", "slit.lammpstrj",
    atom_style="id type x y z",
    dt=0.002,  # ps per integration step; dump interval is 25000 steps
)
analyze(
    traj,
    walls="type 1",
    liquid="type 2",
    rho_bulk=3.0,
    average_from="2 ns",
    average_to="10 ns",
    block="0.5 ns",
    prefix="lammps",
)

Write a compatible dump

Use the integration timestep in ps per step for Python’s dt. Here, 25,000 steps × 0.002 ps gives 50 ps between saved frames. With units real, convert the input timestep from fs to ps. With units lj, convert reduced distances and times consistently before using physical nm and ps labels. PANDA's MDAnalysis reader converts input Å to nm.

Shell
write_data slit.data
dump trajectory all custom 25000 slit.lammpstrj id type x y z
dump_modify trajectory sort id
