synthetic_profile

panda_md.synthetic_profile

synthetic_profile(
    model: core.model.InterfaceModel,
    values: Mapping[str, float],
    *,
    density_bulk_per_nm3: float,
    bin_count: int = 200,
    noise_std: float = 0.0,
    frame: core.enums.Frame = Frame.PORE,
    offset: float = 0.0,
    seed: int | NoneType = None,
    noise_model: core.enums.NoiseModel = NoiseModel.CONSTANT,
    sampling: core.enums.ProfileSampling = ProfileSampling.CENTER,
) -> core.profile.DensityProfile

Generate a one-dimensional profile for known model parameters. Set seed for repeatable noise.

Parameters

ArgumentMeaning
valuesModel parameters in user units, including theta in degrees where applicable.
noise_std, noise_model, seedNoise magnitude relative to bulk density, its scaling rule, and the random seed.
samplingEvaluate at bin centers or average within each bin.
