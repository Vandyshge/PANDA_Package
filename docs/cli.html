Command line

Use panda to build profiles, fit a known shape, or compare candidate models from the shell.

Inspect available models

Shell
panda shapes --pore slit
panda profile --help
panda fit --help

Create a profile and fit it

Shell
panda profile system.tpr system.xtc --walls "resname GRAPHITE" --select "resname WATER and name OW" --start "2 ns" --block "1 ns" -o water.npz --pore-output pore.json
panda fit water.npz --pore-file pore.json --shape roll --rho-bulk 33.1 --blocks -o result.json

Use --shape auto to compare supported candidates and --plot fit.png with the plotting extra. The exit codes are 0 for success, 1 for an input error, and 2 for a completed fit with diagnostic flags.

Save the workflow in TOML

TOML
[pore]
type = "slit"
wall_selection = "resname GRAPHITE"

[profile]
topology = "system.tpr"
trajectory = ["system.xtc"]
select = "resname WATER and name OW"
start = "2 ns"
block = "1 ns"

[fit]
shape = "roll"
density_bulk_per_nm3 = 33.1
blocks = true
output = "result.json"

Save as panda.toml and run panda run panda.toml. Input paths are relative to the settings file.
