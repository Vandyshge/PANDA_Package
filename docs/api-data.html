density_profile

panda_md.density_profile

density_profile(
    trajectory: core.trajectory.Trajectory,
    pore: core.pore.Pore,
    select: str | Sequence[int],
    *,
    centering: core.enums.ProfileCentering | str | None = None,
    bins: int = 200,
    bin_width_nm: float | None = None,
    start: float | str = 0.0,
    stop: float | str | None = None,
    block: float | str | None = None,
    stride: int = 1,
    pore_center_nm: float | None = None,
    orientation: core.enums.Orientation | str = Orientation.AUTO,
    per: core.enums.ParticleGrouping | str = ParticleGrouping.ATOM,
) -> core.profile.ProfileSet

Bin number density along the pore axis. The selection accepts an MDAnalysis selection string or atom indices. A numeric time is in ps. A block setting produces time-resolved profiles.

Parameters

ArgumentMeaning
bins, bin_width_nmSet the bin count or the width in nm.
start, stop, strideSelect a frame interval and subsample it. Time can be numeric ps or a string such as '2 ns'.
blockLength of a time block. The default returns a ProfileSet with one averaged profile.
centering, orientationChoose the coordinate origin and whether PANDA may reflect the pore-frame profile.
perCount atoms or molecule centers of mass.
