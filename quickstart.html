Quick start

Generate a noisy slit-pore roll profile with a known angle, then fit it with PANDA.

Generate and fit a profile

The slit is 8 nm wide. The synthetic model uses θ = 120°, a layer thickness of 0.03 times the slit width, and a liquid volume fraction of 0.40.

from panda_md import SlitPore, synthetic_profile

pore = SlitPore(width_nm=8.0, length_nm=16.0)
roll = pore.interface("roll")
truth = {"theta": 120.0, "delta": 0.03, "phi": 0.40}
profile = synthetic_profile(
    roll, truth, density_bulk_per_nm3=30.0,
    noise_std=0.005, seed=0,
)
result = roll.fit(
    profile, optimize=["theta", "delta"], density_bulk_per_nm3=30.0,
)
print(f"theta = {result.values['theta']:.2f} deg")
print(f"delta/H = {result.values['delta']:.4f}")
print(f"phi = {result.values['phi']:.4f}")
print(f"L1 loss = {result.loss:.5f}")
print(result.problems())

Read the result

theta = 120.61 deg
delta/H = 0.0301
phi = 0.4002
L1 loss = 0.00377
[]

These values come from the archived run for this example. PANDA optimizes θ and δ. It derives φ from the profile using the supplied bulk density. The last line is the list of fit flags.
