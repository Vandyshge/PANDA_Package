Python API

A reference to the main objects and functions in the panda_md namespace.

Geometry and fitting

SlitPore, TrianglePore, SquarePore, CylinderPore
Store pore dimensions in nm. Call pore.interface(shape) to construct an InterfaceModel.
InterfaceModel.fit(profile, **settings)
Fit one morphology to one DensityProfile.
FitSpec
Reusable fit settings, including normalization, free and fixed parameters, and bounds.
FitResult
Inspect values, loss, summary(), and problems().

Profiles and trajectories

load_trajectory(topology, *trajectory_files, **options)
Read MD files through MDAnalysis. For in-memory data use ArrayTrajectory.
density_profile(trajectory, pore, select, ...)
Build density profiles, optionally split into time blocks.
DensityProfile, ProfileSet
Represent one profile or a series. A profile set provides mean(), sem(), and block(i).
density_map(...), synthetic_profile(...)
Compute a two-dimensional density map or generate a synthetic one-dimensional profile from known model parameters.

Analysis and plotting

fit_blocks(model, profiles, spec=None)
Fit each block and summarize parameter means and spread.
compare_shapes(pore, profile, spec)
Rank fitted models and report skipped or near-indistinguishable candidates.
stability_diagram(pore, *, contact_angle_deg, wall_layer, volume_fractions, length_ratios, shape_names=None)
Find minimum-energy candidates over a grid of liquid fractions and reduced pore lengths.
panda_md.plotting
Optional plotting helpers including plot_fit and plot_density_map.

For full signatures and extension guides, see the developer manual (repository access required).
